{% comment %} Animated 3D scenery behind the live chart. Usage — place it inside the element that holds the live chart on the present screen:
{% include "games/partials/_env_3d.html" with chart_background=quiz.chart_background %} ... the chart / answer bars render above this ...
The parent MUST be position:relative or the canvas will escape it. Requires (once per page): The canvas is absolutely positioned and pointer-transparent, so it always sits behind the chart content. Falls back silently (no canvas) without WebGL, and skips mounting entirely when the viewer prefers reduced motion. Teardown: `window.kkEnv3d.destroy()` if your presenter screen swaps questions without a page load. The old version exposed the handle but never released the previous one, so navigating between five questions left five WebGL contexts running — browsers cap these at around sixteen and then start killing the oldest.{% endcomment %}
