Geofence zones

Zones are named areas (circle or polygon). Use them to show questions only inside/outside an area, or to limit which cascading options appear at the respondent's location.

Lookup datasets

Preloaded records for follow-ups: link a barcode / QR question to a dataset and enumerators scan (or type) a code to pull the matching record and auto-fill answers. First CSV column is the match key by default. Re-uploading the same name replaces the data.
