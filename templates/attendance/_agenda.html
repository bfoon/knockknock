{% comment %} Renders an event's agenda in whichever of the ten visual styles the organiser picked. This used to be a ten-branch {% if %}/{% elif %} chain listing every style by name — written out TWICE, once for the multi-day path and once for the no-days path. Forty lines to express "include the partial named after agenda_template_key", and two copies that had to be kept in step: adding an eleventh style meant editing both chains, and missing one silently fell through to `timeline`. `{% include %}` accepts a variable, so the view (or the filter below) resolves the key to a path once. The key is validated against AGENDA_TEMPLATE_KEYS before it becomes a path — a template name assembled from a database field is a directory-traversal hole otherwise, and the model's `max_length=32` CharField is not a whitelist.
